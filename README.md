# KraftLink

Connecteur KraftInk pour Bukkit, Spigot, Paper, Folia, Velocity et Hytale. Le module Bukkit cible Minecraft 1.8.x à partir de 1.8.8 et Java 8. Chaque serveur ou proxy conserve ses propres prérequis Java.

Compilation complète avec JDK 25 et Maven :

```shell
mvn clean package
```

Le build complet fournit `target/KraftLink.jar` et les variantes Bukkit, Velocity et Hytale dans ce même dossier. Installez un seul JAR par instance. Consultez les guides [d’installation](https://kraftink.com/fr/documentation/kraftlink/) et [de développement](https://kraftink.com/fr/documentation/developpement-kraftlink/).
